# QuebecRetention

Retention for Quebec Law 25: destroy or anonymize personal information once its purposes are achieved, with tombstones that re-apply it after a backup restore

## Installation

You can install the package via composer:

```bash
composer require jeffersongoncalves/laravel-quebec-retention
```
